# Flight Delays Analysis Project ✈️

## 📝 Project Overview
This project provides a comprehensive analysis and interactive dashboard for flight delays using a dataset of 3 million flights. The primary goal is to identify delay patterns, understand root causes, and present dynamic visualizations through a web-based dashboard built with Streamlit.

---

## 🎯 Business & Analytical Questions
The project addresses five key analytical domains:
1. Airline Performance: Volume of flights, delay stats, and top delayed carriers.
2. Delay Behavior: Statistical distribution of departure and arrival delays (Mean vs. Median).
3. Temporal Patterns: Delay trends across different days of the week and months of the year.
4. Distance vs. Delay: Evaluating correlation between flight distance and departure delays.
5. Multiple Delay Causes: Identifying primary delay drivers (Late Aircraft, Carrier, Weather, NAS).

---

## 🛠 Technologies Used
- Python 3
- Pandas & NumPy: Data manipulation and sample optimization.
- Plotly Express & Seaborn: Interactive and static visual analytics.
- Streamlit: Interactive web dashboard framework.
- Jupyter Notebook: Exploratory data analysis environment.

---

## 🚀 Interactive Streamlit Dashboard
The repository includes app.py, an interactive dashboard that allows uploading CSV datasets to explore top delayed airlines and origin airports in real-time.
